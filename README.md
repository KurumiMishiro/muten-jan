# 無聴雀（ブラウザ版）

麻雀の CPU 対戦ゲームです（三人・四人）。スマホ・PC のブラウザでそのまま遊べます。

**▶ 遊ぶ： https://kurumimishiro.github.io/muten-jan/**

- 3人・12枚＋見えない「無牌」、東南戦
- 相手が手牌の **どこから切ったか**、ツモ牌を **どこへ差し込んだか** が見えるのが特徴です
- 通信なしで動きます（一度開けばオフラインでも起動できます）
- ホーム画面に追加すると、アプリのように全画面で遊べます
- タイトル画面で4つのルールを選べます
  - 左上 **無聴雀**：3人・12枚＋無牌
  - 右上 **宇宙麻雀**：無聴雀＋誰の捨て牌からでもチーできる
  - 左下 **四人麻雀**：標準ルール（25000点持ち30000点返し、ウマ +15/+5/−5/−15、西入あり）
  - 右下 **三人麻雀**：標準ルール（萬子2〜8抜き、北は役牌、35000点持ち40000点返し、ツモ損、西入あり）
- 右上の ♪ ボタンで BGM（このゲームのためにプログラムで作曲・合成したラウンジ・ジャズ3曲／オフ）を切り替え
- 卓の中央に残りツモ枚数を表示、対局終了時には持ち点とウマ込みの順位点（例：+45.0）を表示します

## 操作（スマホ）

- 牌をタップで選ぶ → もう一度タップで打牌（設定で「1回タップで打牌」にもできます）
- 牌を長押し、または左右にドラッグで並べ替え（自動では並びません。［理］を押したときだけ並べます）
- 左のボタン：［理］理牌　［立］リーチ　［開］オープンリーチ　［和］ツモ／ロン　［鳴］ポン　［吃］チー（宇宙麻雀・四人麻雀）　［槓］カン　［▶］見送り
- 横向きがおすすめです（縦向きでも遊べます）

設定はこの端末のブラウザ内（localStorage）にだけ保存されます。外部への送信はありません。
